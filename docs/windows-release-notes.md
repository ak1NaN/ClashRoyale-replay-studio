# Windows 首个预览版

导入 RoyaleAPI 独立对局 HTML，在 MuMu 中通过 Nulls Royale 原生游戏画面播放重建回放。支持暂停、时间轴跳转和 0.25×～16× 倍速。

## 环境要求（请先阅读）

- **必须使用 Android 12 的 MuMu 模拟器实例，开启 ADB 和 root。**
- **暂不支持 Android 15：当前反馈该环境下 Nulls Royale 无法打开，原因尚未查明。** Android 12/15 是模拟器内的系统版本，不是 MuMu 软件版本。
- 实测主机为 Windows 11 x64、MuMu 6.6.4.0、Android 12。
- 游戏需要 Nulls Royale **15.535.13** 及匹配资源；先联网完成资源下载。软件会校验游戏库，不支持任意最新版。

## 下载哪个文件

- **ReplayStudio-Windows-x64.exe**：独立运行版，无需安装 Python。启动时会解压内置组件，请稍等片刻。
- **ReplayStudio-Windows-x64-preview.zip**：完整目录版，解压后打开 `Replay Studio.exe`；不能只复制里面的 exe。
- **SHA256SUMS.txt**：上述文件的 SHA256 校验值。

这是未签名预览版本，请核对下载来源与校验值，不要关闭系统安全设置。

## 使用步骤

1. 打开 Android 12 的 MuMu，开启 ADB/root，让匹配版本游戏进入主界面。
2. 打开回放工作室，导入保存的 RoyaleAPI **独立对局 HTML**。
3. 点击“准备回放”，等待预演算和场景创建，然后播放。游戏画面显示在模拟器中。
4. 正常关闭控制窗口，程序会清理组件并恢复游戏联网。

ADB 和实例会自动发现；失败时在连接设置填写实际路径与端口。准备回放期间会暂时阻止联网，部分 MuMu 环境会影响整个模拟器实例，正常退出后恢复。

## 本次修复与验证

- 修复 Windows Native Bridge 创建回放场景时的崩溃。
- 修复断线事件导致播放十几秒后冻结。
- 已在一台实机上用含 64 个动作的真实 HTML 完成整场原生 1× 播放至结局，并验证跳转、七档倍速和恢复联网。
- 单元测试 43 项通过、3 项跳过；更多设备与对局仍待验证。

HTML 不包含原始随机种子和秘密初手，因此是相容重建，不能保证时间、伤害或结局与原局完全相同。此预发布来自 `win` 分支，不替换现有 Mac Release。项目不包含游戏或模拟器，也不隶属于 Supercell。
